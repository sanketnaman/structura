# Blog Image Assets Directory

Local optimized WebP assets for MixTally blog articles. All files are served locally (no hotlinking, no third-party image URLs).

These assets are **original illustrations authored for MixTally**. The first four were drawn as vector SVG documents and rendered to WebP locally with sharp/librsvg on the project machine; `how-much-paint-room.webp` is a raster hero (1536x1024 WebP) supplied as a local asset for the paint quantity article, with the article title and worked-example figures rendered into the artwork. There is no upstream photograph, stock file or AI-generated source to link to in any of them. No publisher, brand name or packaging artwork is reproduced in any of them.
