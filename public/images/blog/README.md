# Blog Image Assets Directory

Local optimized WebP assets for MixTally blog articles. All files are served locally (no hotlinking, no third-party image URLs).

These four assets are **original illustrations authored for MixTally**. They were drawn as vector SVG documents and rendered to WebP locally with sharp/librsvg on the project machine; there is no upstream photograph, stock file or AI-generated source to link to. No publisher, brand name or packaging artwork is reproduced in any of them.
